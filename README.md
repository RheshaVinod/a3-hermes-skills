# A3 Hermes Skills

Public Hermes skill tap for Rhesha Vinod's CSCI 599 Assignment 3.

## Deadline Risk

Assesses a synthetic project deadline against estimated remaining work and
recommends a focus action. The skill expects the Assignment 3 `a3ctl` command
to be available.

Install the tap and skill:

```sh
hermes skills tap add RheshaVinod/a3-hermes-skills
hermes skills install RheshaVinod/a3-hermes-skills/skills/deadline-risk
```

Or install the single-file skill directly from its pinned raw GitHub URL.

Use only synthetic project names and dates. This repository intentionally
contains no credentials, private evidence, account information, or user data.
